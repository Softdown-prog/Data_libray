# Busca binária Rust

Retorna a primeira posição de um i32 em fatia ordenada sem alocação adicional.

**Linguagem:** rust · **Categoria:** algorithms · **ID:** `rust.algorithms.binary-search`

## Executar

```bash
cd rust && cargo run -p binary-search-example
```

## Validar

```bash
cd rust && cargo test -p binary-search-example
```

**Observação:** este exemplo é independente dos demais e deve permanecer pequeno, legível e reproduzível.
