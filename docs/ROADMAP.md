# Plano incremental para 10.000–12.000 exemplos

A base prioriza curadoria, não número artificial.

| Fase | Meta acumulada | Critério |
| --- | ---: | --- |
| Fundação | Primeiros exemplos reais | CI, catálogo, busca, documentação |
| Cobertura básica | 500 | Algoritmos, I/O, erros, testes |
| Expansão | 2.000 | APIs, web, concorrência, UI, segurança |
| Cobertura avançada | 5.000 | Bancos, padrões, desempenho, arquiteturas |
| Especialização | 10.000 | Casos reais, edge cases, plataformas |
| Maturidade | 12.000 | Revisão de duplicidade, cobertura e manutenção |

Lotes pequenos (~25–100) organizados por área e checados em PRs; nunca gerar arquivos apenas para atingir cotas. O catálogo permite encontrar snippets por termo, linguagem e categoria. Um futuro MCP pode consultar o mesmo índice JSON e acrescentar pesquisa semântica.
