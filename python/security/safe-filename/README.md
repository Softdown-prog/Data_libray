# Nome de arquivo restrito

Valida nomes simples de arquivos e bloqueia separadores e sequências de caminho.

**Linguagem:** python · **Categoria:** security · **ID:** `python.security.safe-filename`

## Executar

```bash
python python/security/safe-filename/solution.py
```

## Validar

```bash
python python/security/safe-filename/test_solution.py
```

Não substitui validação de permissões, isolamento do diretório e proteção contra symlinks ao abrir arquivos.
