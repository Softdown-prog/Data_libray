# Busca binária Python

Busca a primeira posição de um inteiro em lista ordenada, inclusive com valores repetidos.

**Linguagem:** python · **Categoria:** algorithms · **ID:** `python.algorithms.binary-search`

## Executar

```bash
python python/algorithms/binary-search/solution.py
```

## Validar

```bash
python python/algorithms/binary-search/test_solution.py
```

Complexidade O(log n) e memória O(1). A lista deve estar ordenada.
